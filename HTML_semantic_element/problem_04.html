NovaBook Pro 15

The NovaBook Pro 15 is our flagship laptop, designed for professionals, students and creators who need reliable performance in a slim, portable body.

Product Overview

Available in four configurations, the NovaBook Pro 15 pairs an 11th/13th Gen Intel Core processor with a bright Full HD or OLED display, giving you options that scale from everyday use to demanding creative workloads.

Battery life is rated at up to 9 hours on a single charge*, making it suitable for a full day of classes or meetings without needing to carry a charger.

*Battery life is based on typical usage and may vary with settings and workload.

Key Features

  • Backlit keyboard
  • Fingerprint reader for quick sign-in
  • Fast charging support
  • Dual-band Wi-Fi 6E
  • Thunderbolt 4 ports
  • Aluminum chassis
  • Full HD / OLED display options
  • Dolby Atmos speakers

Technical Notes

After completing setup, you can view your laptop's full system configuration at any time. Open Command Prompt and run the following command: 

systeminfo

This displays details such as processor, installed memory and system type, which is useful when contacting technical support.

Every NovaBook Pro 15 configuration includes a manufacturer warranty covering hardware defects. Base and Plus configurations include 1 year of coverage, while Performance and Elite configurations include 2 years. Extended warranty plans can be purchased separately at the time of order.

Key Terms

RAM
Random Access Memory used by the system to run active programs; higher RAM allows smoother multitasking.
SSD
Solid State Drive; the storage used for the operating system, apps and files, offering fast read/write speeds.
Refresh Rate
The number of times per second the display updates its image, measured in Hz.
Warranty
The manufacturer's coverage period for repairing or replacing hardware defects.
