JavaScript

JavaScript is mainly used to make web pages interactive. It runs directly in the browser and helps handle things like button clicks and form validation. One important concept in JavaScript is variables, which are used to store data.

console.log("Hello World");

Java

Java is a widely used programming language for building applications, from mobile apps to large software systems. Every Java program must have a main method, which is where the program starts running.

System.out.println("Hello World");
